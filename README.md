# 📌 WindowPin — Windows 窗口置顶小工具

一个轻量的 Windows 窗口置顶工具：**按一下热键，当前窗口立刻置顶；再按一下取消**。
置顶期间会在窗口标题栏中间显示一个红色小图钉作为状态提示，点击图钉即可取消置顶。

- 单文件绿色版 exe，无需安装、无需管理员权限
- 只用 Win32 API 实现，**不做 DLL 注入、不修改目标进程**，对任何程序都安全
- 能扛住「抢置顶」的程序（如微信），周期性加固置顶状态
- 热键可自定义并持久化，冲突时明确提示
- 托盘常驻，右键菜单只有两项：更改热键 / 退出

---

## 效果说明

| 操作 | 结果 |
| --- | --- |
| 按热键（默认 `Ctrl+Alt+Shift+P`） | 当前前台窗口 → 置顶，标题栏中央出现红色 📌 |
| 再次按热键 | 取消置顶，📌 消失 |
| 左键单击托盘图标 | 同热键（切换置顶 / 取消） |
| 左键单击标题栏上的 📌 | 取消该窗口的置顶 |
| 托盘图标右键 | 菜单：`更改热键…`、`退出` |

图钉是**状态指示器**，不是需要先「挂钉」的操作入口——一步到位，不需要两步操作。

## 快速开始

### 方式一：直接用 exe（推荐）

1. 下载 `WindowPin.exe`
2. 双击运行，程序会常驻系统托盘（通知区域）
3. 切到任意窗口，按 `Ctrl+Alt+Shift+P` 即可置顶

> 说明：单文件 exe 首次启动需要解包，可能有 1–3 秒延迟，属正常现象。

### 方式二：从源码运行

```bash
# 1. 安装依赖（需要 Python 3.8+，建议 3.12）
python -m pip install -r requirements.txt

# 2. 运行
python window_pin.py
```

依赖仅三个：

```
pywin32
pystray
Pillow
```

## 自定义热键

1. 右键点击托盘图标 → `更改热键…`
2. 在弹窗里直接按下你想要的新组合键
3. 如果该组合已被其它程序占用，会提示 **「该热键冲突，请更换！」**，且原热键保持不变
4. 设置成功后立即生效，并保存到 `%APPDATA%\WindowPin\config.ini`，下次启动自动恢复

## 工作原理

程序由三部分组成，全部基于 Win32 消息循环：

1. **Host 隐藏窗口** —— 承载全局热键注册（`RegisterHotKey`）与整个消息循环，单实例运行。
2. **PinWindow 图钉窗口** —— 一个 `WS_EX_LAYERED | WS_EX_TOPMOST` 的分层弹出窗口，用 `UpdateLayeredWindow` 绘制带 Alpha 的彩色 📌 表情（GDI 直接绘制表情只能得到黑白，因此必须走分层窗口 + PIL 渲染）。
3. **CaptureDialog 热键录制窗口** —— 捕获用户按键，做冲突检测后再提交给 Host。

几个关键实现细节：

- **置顶加固**：每 `150ms × 6 ≈ 0.9s` 对目标窗口重新执行一次 `SetWindowPos(HWND_TOPMOST)`，用于抵抗微信等会抢回 Z 序的程序。
- **图钉不被遮挡**：每次加固后都会检查图钉是否被目标窗口盖住，若被盖住立刻把图钉重新抬回最顶层，否则会出现「图钉约 1 秒后消失」的问题。
- **跟随**：图钉位置在每次定时器 tick 时按目标窗口矩形重新计算，因此窗口移动 / 缩放时图钉会跟随，窗口最小化时图钉自动隐藏。
- **单实例**：通过命名互斥体 `Global\WindowPinToolMutex` 保证只跑一个进程，重复启动会把「切换置顶」消息转发给已运行实例。

## 常见问题

**Q：置顶后看不到图钉？**
确认目标窗口有标准标题栏（无边框全屏窗口没有标题栏，图钉会落在窗口左上角区域）。另外图钉位于标题栏**水平居中**，不会盖住最大化 / 关闭按钮。

**Q：热键按了没反应？**
可能被其它程序占用，换一个组合即可。设置时如果冲突，程序会明确提示。

**Q：exe 图标显示成旧的灰图钉？**
这是 Windows 图标缓存问题，与文件本身无关。把 exe 改名或换个目录，或运行仓库里的 `刷新图标缓存.bat`。

**Q：某些程序（如微信）置顶后又被压下去？**
程序已内置周期性置顶加固，正常情况会持续保持在最前。
